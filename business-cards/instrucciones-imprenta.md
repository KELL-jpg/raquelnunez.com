# Instrucciones para Imprenta

Proyecto: Tarjeta profesional de Lcda. Raquel Núñez Alicea

## Formato

- Tamaño final: 3.5 x 2 pulgadas
- Tamaño del archivo con bleed: 3.75 x 2.25 pulgadas
- Bleed: 0.125 pulgadas por cada lado
- Margen seguro: mantener texto y logo dentro de 0.25 pulgadas desde el borde final
- Impresión: doble cara, orientación horizontal
- Exportación recomendada: PDF en alta calidad, escala 100%, sin ajustar a página

## Color

Usar impresión full color. Estos son los colores base del diseño:

- Azul petróleo principal: HEX #1B3A4B
- Azul petróleo profundo: HEX #102836
- Dorado principal: HEX #B8962E
- Dorado suave: HEX #D7BE63
- Crema: HEX #F5F0E8
- Tinta azul para texto: HEX #122838

Nota para imprenta: convertir a CMYK según el perfil de color del proveedor, manteniendo el dorado como tono cálido sobrio, no amarillo brillante. Si ofrecen prueba digital, revisar especialmente contraste del dorado sobre azul petróleo.

## Acabado sugerido

- Papel: 16 pt o superior
- Acabado: matte o soft-touch
- Evitar glossy fuerte para conservar una apariencia profesional y elegante
- Bordes rectos, sin esquinas redondeadas salvo instrucción posterior
